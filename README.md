# Smart App Master

Smart App Master 1.0.0 هو تطبيق Android لإدارة اختصارات التطبيقات والوصول السريع إلى إعداداتها وأدوات خصوصية الهاتف.

## الوظائف
- عرض التطبيقات القابلة للتشغيل والبحث بينها واختيار تطبيق.
- تشغيل التطبيق المختار مباشرة.
- فتح إعدادات إشعارات التطبيق وإعداداته وصلاحياته في Android.
- عرض معلومات الذاكرة المتاحة والبطارية وحرارتها عندما يوفر النظام هذه البيانات.
- وضع عدم الإزعاج العام عبر صلاحية Android الخاصة، بعد موافقة المستخدم.
- حفظ التطبيق المختار محلياً على الهاتف.

## الخصوصية والحدود
- لا يجمع التطبيق بيانات ولا يرسلها إلى خادم.
- وضع عدم الإزعاج يؤثر على الهاتف عموماً، ويمكن للمستخدم إيقافه يدوياً.
- التحكم بإخفاء معاينة الإشعارات يتم من إعدادات Android.
- لا يمكن لتطبيق خارجي التحكم في خوادم Tango Live أو ضمان استمرار بث مباشر أثناء التنقل داخل Tango إذا لم يدعم Tango أو Android ذلك.
- لا يمكن للتطبيق قراءة FPS لتطبيق آخر أو تغيير طريقة عمله الداخلية بسبب عزل التطبيقات في Android.
- كل إعدادات التطبيقات الأخرى تظل تحت تحكم Android وموافقة المستخدم.
