# Smart App Master

نسخة تجريبية أولى لتطبيق Android مستقل يساعد على اختيار التطبيقات المثبتة وحفظ ملف إعدادات أساسي لكل تطبيق.

## البناء
يعمل GitHub Actions تلقائياً عند كل تحديث على فرع main، ويمكن تشغيله يدوياً من تبويب Actions.

## حدود النسخة 0.1.0
- تعرض التطبيقات التي يوفّرها Android كأنشطة تشغيل.
- تسمح باختيار تطبيق وحفظ اختياره.
- تحفظ تفضيل وضع الخصوصية داخل Smart App Master فقط.
- لا تغيّر إعدادات التطبيقات الأخرى ولا تتجاوز قيود Android أو Tango Live.
- لا تتضمن بعد مراقبة FPS/الحرارة أو مساعداً عائماً أو تحكماً عاماً بالإشعارات.

اسم الحزمة: com.smartappmaster
